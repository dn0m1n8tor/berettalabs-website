Fintech App API Penetration Testing

Identified broken object-level authorization in core banking APIs, preventing unauthorized access to financial transactions.

The Challenge

A fintech startup's mobile app was backed by a set of REST APIs handling transfers, balances and statements. Regulatory and customer trust demanded that these APIs be bulletproof against authorization abuse.

Our Approach

We mapped the complete API surface from the mobile app, then ran a cross-account authorization matrix — testing every endpoint as one user against another user's objects to surface BOLA and BFLA flaws.

Key Results

  • Critical BOLA exposing other users' transactions and balances
  • Function-level authorization gaps on admin-only endpoints
  • JWT validation weaknesses in the authentication layer
  • Full remediation verified prior to the app's public launch
